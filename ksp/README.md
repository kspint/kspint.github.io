# KS & Partners Consultancy Website

Responsive multi-page website built with HTML5, CSS3, JavaScript and Bootstrap 5.3.

## Pages
- English: Home, About, Services, Architecture & Urban Design, Project Management, Cost Consultancy, Sustainability Advisory, Blog, Contact
- Arabic RTL versions in `/ar/` for the same page groups
- Shared service dropdown with icon-led horizontal service links
- Transparent high-contrast logo variants for header/footer and logo preloader, enquiry popup on pages, contact forms, WhatsApp and call shortcuts, back-to-top control
- SEO descriptions, Open Graph metadata, `robots.txt`, and starter `sitemap.xml`

## Preview
Open `index.html` in a browser or serve this folder from a local web server. Bootstrap, Bootstrap Icons, Google Fonts and photography use CDN/remote URLs and need an internet connection.

## Before launch
1. Confirm the exact service list, company legal details and preferred brand colors.
2. Replace the sample editorial content with approved articles and add real project imagery.
3. Connect forms to a secure backend or CRM. Current forms open the visitor's email application with prefilled details; they do not send data to a server.
4. Confirm the logo artwork and ensure it has sufficient contrast on the dark footer/header backgrounds.
5. Update canonical URLs and sitemap if the production domain or page URLs differ.
